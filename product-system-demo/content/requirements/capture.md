## 功能需求

系统在后台监听系统剪贴板，自动捕获并解析每次复制的内容。

| 编号 | 需求 | 优先级 | 状态 |
|---|---|---|---|
| FR-101 | 监听系统剪贴板变化，捕获延迟 ≤ 500ms | P0 | 已确认 |
| FR-102 | 类型识别：文本 / 链接 / 图片 / 文件 / 颜色 | P0 | 已确认 |
| FR-103 | 连续相同内容去重，合并使用计数并置顶 | P0 | 已确认 |
| FR-104 | 忽略指定应用（密码管理器等敏感来源） | P1 | 待确认 |
| FR-105 | 富文本同时保留纯文本副本 | P2 | 待确认 |

## 分类规则

- 纯 URL 字符串 → **链接**
- `NSPasteboard` 图片对象 → **图片**
- 多文件批量复制 → **文件**（聚合为一条，显示数量）
- 十六进制色值 / `NSColor` → **颜色**
- 其余 → **文本**
