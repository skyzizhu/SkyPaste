## 性能需求

| 指标 | 要求 | 验证方式 |
|---|---|---|
| 捕获延迟 | 复制到列表可见 ≤ 500ms（P95） | 埋点 `capture_latency` |
| 面板冷启动 | ≤ 300ms | 埋点 `panel_open` 耗时 |
| 搜索响应 | 10 万条库存下 ≤ 100ms | 本地基准测试 |
| 常驻内存 | ≤ 80MB（1 万条库存） | Instruments 抽检 |
| 存储占用 | 1 万条典型混合内容 ≤ 500MB | 安装后统计 |

## 安全与隐私

- 所有内容仅存储于本机，**任何情况下不上传**（含遥测不含内容，仅事件名与长度）
- 忽略名单应用的内容在捕获层直接丢弃，不落盘
- 回收站条目 7 天后物理删除，不可恢复
- 卸载时提供「清除全部数据」选项

> ⚠️ **待确认**：回收站期间的数据是否需要应用级加密（防止本地磁盘被直接读取）？涉及成本与性能权衡。

## 兼容性

| 维度 | 范围 |
|---|---|
| 系统 | macOS 13 / 14 / 15 |
| 架构 | Apple Silicon（原生）+ Intel（Rosetta 外原生编译） |
| 显示 | 深色 / 浅色模式跟随系统、多显示器、Retina |
| 输入 | 外接键盘快捷键与笔记本键盘一致 |

## 可靠性

- 崩溃率 ≤ 0.1% 会话
- 条目库损坏时自动从最近快照恢复，快照每 24h 一次
- 升级数据库结构采用迁移脚本，保证历史条目无损

## 无障碍

- 面板全部控件支持 VoiceOver 标签
- 快捷键不与系统保留组合冲突；提供键盘完整操作路径（无需鼠标）
