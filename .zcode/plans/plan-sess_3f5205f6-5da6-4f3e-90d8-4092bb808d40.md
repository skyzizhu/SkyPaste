# Windows 版 UI 全面改造：Windows 11 Fluent 风格（WPF-UI 库）

## Context

Windows 版功能已完备，但 UI 是 Mac 风格的硬翻译且存在一批窗口行为 bug，实际使用中"根本不能用"：

1. **偏好设置打不开**（根因已定位）：主面板永远置顶（Topmost），设置/统计/预览窗不置顶、不进任务栏——它们其实打开了但被面板压住，且不进 Alt+Tab 无法抢救。
2. **统计窗图表根本不绘制**：周期按钮的 Content 是字符串却被代码强转为 TextBlock → InvalidCastException 被 `Reload()` 空 catch 吞掉，后续 DrawTrend/DrawDonut/DrawApps 全部跳过。
3. **交互/风格混乱**：Esc 行为各窗不一致、控件全是 WPF 默认样式（深色模式下呈系统亮色）、胶囊按钮/iOS 灰/Mac 调色板直译、系统标题栏与圆角内容混搭、预览窗可无限多开、异常被静默吞掉。
4. 用户确认的方向：**WPF-UI 开源库**（lepoco/wpfui 4.3.0，MIT，net8.0-windows，活跃维护）实现 Windows 11 Fluent 风格；**设置页用 Windows 设置式左导航**；主面板 **X = 隐藏到托盘**（Win11 标题栏按钮规范重做）；**工具窗口标准化**（进任务栏、可 Alt+Tab、Owner 归属面板保证不被遮挡）。

原则：**业务与功能交互遵循 Mac 版语义**（筛选器、搜索语法、批量、收藏、按天分组、热键、粘贴回、网页剪贴板、局域网同步全部不动）；**外壳、控件、窗口行为全面 Windows 11 化**。

## 实施方案（在 feature/win11-fluent-ui 分支，分阶段提交，PR 合并）

### 阶段 0：先修"不能用"的 bug（独立提交，任何后续失败也不影响）

1. **工具窗口 Owner 归属**：`AppCoordinator` 创建设置/统计/预览/调试窗时 `Owner = 主面板（若可见）`；窗口 `ShowInTaskbar=true`、移除 `Topmost`、移除 `WindowStyle=ToolWindow`——设置窗立刻可见、进任务栏、可 Alt+Tab。
2. **统计窗强转 bug**：`DrawPeriodButtons()` 不再强转 Content（XAML 改放 TextBlock，代码兼容两者）。
3. **异常不再静默**：`App.DispatcherUnhandledException` 写入 `%APPDATA%\SkyPaste\logs\ui-*.log` 并弹系统错误框（一次性），杜绝"看起来没反应"。
4. 小修：DebugWindow 重复的 EnableRoundedCorners；死代码 `AddSectionCard`；monospace 字体改 `Cascadia Mono, Consolas`。

### 阶段 1：WPF-UI 引入 + 主题体系重构

1. csproj 添加 `WPF-UI 4.3.0`；App.xaml 合并库的主题资源字典。
2. **ThemeService 重写**：对外 API 不变（`ApplyCurrentSetting/ThemeChanged`），内部改用 WPF-UI 的 `ApplicationThemeManager`（Light/Dark/System 三态 + 跟随系统实时切换）；我们自定义的 `Theme.Light/Dark.xaml` 保留但调色板值 Fluent 化（背景/卡片/描边/文本层级按 Win11 规范，强调色跟随系统 SystemAccentColor，品牌蓝仅用于 logo 场景）；删除 8 个死资源 key。
3. 新增 `Views/Shell/FluentWindowBase` 约定：所有窗口继承 `ui:FluentWindow`，头部用 `ui:TitleBar`（图标+标题+Win11 式最小化/最大化/关闭按钮），`WindowBackdropType=Mica`（Win11 22H2+ 生效，Win10 自动回退纯色，由库处理）。

### 阶段 2：逐窗口改造

1. **主面板 MainWindow**：无边框 FluentWindow + TitleBar 与面板 header 融合（左：logo+SkyPaste+快捷键提示；右：Win11 caption 按钮）；`ClipboardListPanel` 主体不变（代码构建的列表/筛选 chips/批量模式是成熟代码），只做调色板 Fluent 化 + `FindResource`→`TryFindResource`（兼容主题切换）；X = 隐藏到托盘（保留现有语义，按钮视觉走 TitleBar）；`WindowEffectsService` 删除（库接管圆角/背景）。
2. **TrayPopoverWindow**：同款无边框样式（无 caption 按钮），保留失焦自动关闭，**补 Esc=关闭**。
3. **SettingsWindow 重构为左导航**：左栏 220px 导航列表（通用/快捷键/同步与隐私/资料库/关于，WPF-UI 图标），右侧 `ContentControl` 切换 5 个页面 UserControl；全部控件换 WPF-UI 样式（ToggleSwitch/ComboBox/TextBox/Slider）；保留 QR 码、防火墙提示、语言/主题即时刷新、事件退订。
4. **StatisticsWindow**：修强转 bug（阶段 0 已修）；周期选择改 Fluent 分段按钮；内容套 ScrollViewer；图表配色走主题资源（不再硬编码）；TitleBar 化。
5. **三个预览窗 + DebugWindow**：TitleBar 化；头部工具条改 Windows 命令栏风格（图标+文字按钮）；标注五色/类别色等硬编码色入主题资源。
6. **Toast/托盘**：Toast 保留（微调对齐 Fluent 视觉）；WinForms NotifyIcon 托盘保留不变。

### 阶段 5：验证

1. `dotnet build` + `dotnet test`（115 测试全绿）。
2. **CI 冒烟截图扩展**：`--uitesting` 支持场景参数（`main`/`settings`/`statistics`），三个窗口各出一张截图工件——你无需 Windows 机器即可看到 Win11 风格实际渲染效果（这套流程今天已验证有效，还抓出过图标字体 bug）。
3. PR → CI 全绿 → 合并 main；发 v0.4.1 Release（四件套自动附上）。

### 关键文件清单

- 修改：`App.xaml/.cs`、`ThemeService.cs`、全部 9 个窗口 XAML+.cs、`ClipboardListPanel.xaml.cs`、`SkyPaste.csproj`（+WPF-UI）、`AppCoordinator.cs`（Owner/单例语义）
- 新增：`Views/Shell/`（SettingsNavPage 等 5 个设置页 UserControl）、Fluent 调色板字典更新
- 删除：`WindowEffectsService.cs`（被 WPF-UI 接管）
- 不动：`SkyPaste.Core` 全部（业务/数据/协议/同步零改动）、`ClipboardMonitor/HotKey/PasteBack/DragOut` 等服务、Mac 端全部

### 风险与对策

- WPF-UI 主题体系与自定义字典并存：自定义 key 全部带命名空间式命名（`Chip.*` 等），已确认无冲突。
- 面板的代码构建 UI 与 FluentWindow 共存：面板内容置于 TitleBar 下方 Grid.Row=1，Mica 上半透明卡片按 Fluent 规范调透明度。
- CI（windows-latest）NuGet restore WPF-UI：标准包，无风险。
- 主面板 Topmost 与新工具窗口层级：Owner 关系保证工具窗在面板之上；面板失焦不隐藏（保持 Mac 语义）。
