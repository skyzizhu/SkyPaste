## 产品定位

SkyPaste 是一款 macOS 菜单栏常驻的剪贴板历史管理工具：自动记录复制过的内容，支持搜索、分类与一键粘贴回任意应用。

- **一句话定位**：「复制过的一切，随时找得回、贴得出」
- **平台**：macOS 13+
- **形态**：菜单栏应用 + 全局快捷键呼出面板

## 目标用户

| 用户 | 典型场景 | 核心诉求 |
|---|---|---|
| 开发者 | 复制代码片段、命令、报错信息 | 快速找回历史片段，多段来回切换 |
| 设计师 | 取色、复制图片与规格标注 | 图片/颜色分类管理，拖出到聊天窗口 |
| 文案 / 运营 | 多版本文案取舍、素材整理 | 多条目暂存、收藏与快速回贴 |

## 竞品与差异化

| 竞品 | 其优势 | SkyPaste 差异化 |
|---|---|---|
| Maccy（开源） | 轻量、免费 | 更完整的类型识别（颜色 / 文件聚合）与条目详情 |
| Paste（订阅制） | 功能全面、跨平台 | 买断制 + 纯本地存储，隐私优先 |
| Raycast 剪贴板 | 生态集成强 | 独立小工具、无平台绑定，专注单一体验 |

## 核心价值

1. 自动捕获，零额外操作
2. 类型识别：文本 / 链接 / 图片 / 文件 / 颜色
3. `⌘1–9` 数字键秒级回贴
4. 全量本地存储，隐私安全
