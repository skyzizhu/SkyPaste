## 名词解释

| 术语 | 定义 |
|---|---|
| 条目 | 一次复制行为产生的内容记录，含内容本体与元数据 |
| 捕获 | 系统检测到剪贴板变化并解析入库的过程 |
| 回贴 | 将历史条目写回剪贴板并粘贴到前台应用的动作 |
| 固定 | 用户置顶的条目，不受容量淘汰影响 |
| 收藏 | 用户标记的条目，跨清理周期保留，可单独过滤 |
| 归档 | 超出容量 / 期限后从主列表移除但未删除的状态 |
| 回收站 | 删除条目的缓冲区，保留 7 天后物理删除 |
| 忽略名单 | 指定应用的复制行为在捕获层直接丢弃 |
| 来源应用 | 触发复制时所在的前台应用 |
| 类型 | 条目的内容分类：文本 / 链接 / 图片 / 文件 / 颜色 |
